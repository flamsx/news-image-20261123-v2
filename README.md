A one-page newspaper front page summing up the world's news of
**Monday 23 November 2026**: 31 stories across 7 regions, every one of
them first reported on that day — no carryover from any other day.

Run it with:

```sh
python3 main.py            # writes /output/entry.png
python3 main.py entry.png  # or to a path of your choice
```

`draw.py` draws the page (masthead, giant date, stat strip, 3 illustrated
lead cards, 10 medium cards, an 18-story brief list, a world map with
numbered pins, and a DATE CHECK box). `main.py` is the entry point.
Fonts are Google Sans (OFL), four static weights under `fonts/`.
